


# 🛍️ VEM QUE TEM

**Acessórios em gerais com estilo, preço justo e qualidade!**

Este é o site oficial do projeto **Vem Que Tem**, uma vitrine moderna de acessórios para todos os gostos: relógios, fones, bolsas, óculos, pendrives e muito mais!

---

### 🌐 Acesse o site:
➡️ [Clique aqui para visitar o site](https://bruno188643.github.io/Vem-que-tem)

---

### 🚀 Funcionalidades:
- Layout colorido, jovem e responsivo
- Integração futura com links de afiliados
- Navegação simples e rápida
- Totalmente otimizado para dispositivos móveis

---

### 📁 Estrutura do projeto:
- `index.html`: Página principal do site
- `style.css`: Estilo visual da página
- `script.js`: Comportamento e interações
- `imagens/`: Pasta com todas as imagens do projeto
